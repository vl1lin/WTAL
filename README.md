# WTAL — анализ ГДИС в браузере

Статичный сайт для работы с данными гидродинамических исследований скважин: таблица в стиле Excel, масштабируемые графики, выделение точек прямо на графике, прямые и линии тренда, калькулятор площади трещин ГРП. Интерфейс на русском, по образу Saphir.

## Возможности

- **Главная страница** — вся история скважины: таблицы давления и дебитов и график «давление сверху, дебит снизу». Выделите участок и нажмите «Данные → Создать исследование»: в исследование копируются выделенные строки давления и история дебитов.

- **Исследования** — несколько наборов данных во вкладках; загрузка из буфера обмена (с правкой прямо в окне), CSV/TXT или ручной ввод; для каждого столбца — физический смысл и единицы.
- **Давление и дебиты загружаются отдельно** — у исследования две таблицы: давление и история режимов (время начала режима, дебит). Δt и p₀ отсчитываются от последнего изменения дебита; по истории строятся суперпозиция (КВД, мультирежим, Агарвал), tp и нормировка Δp/Δq. Время — датой или числом в одной шкале с давлением; в таблице дебитов оно может означать начало или конец режима (как в выгрузках Saphir).
- **Таблица как в Excel** — ячейки с формулами (`=(B3-B2)/D3`, `$A$1`, `SUM(A1:A10)`), протяжка вниз (маркер или Ctrl+D), копирование/вставка, пустые столбцы, ƒx-столбцы с формулой на весь столбец (`=SQRT([Время])`), сортировка без разрыва строк.
- **Графики** — log-log (Δp и производная Бурде), semilog, история, произвольный (Δt, log, √Δt, ⁴√Δt, 1/√Δt; суперпозиция КВД / мультирежим / Агарвал), по столбцам, по выделенным строкам. Окна перетаскиваются, растягиваются, сворачиваются, переименовываются.
- **Инструменты** — приближение рамкой, колесо, сдвиг, масштаб по умолчанию; выделение прямоугольником, лассо, кликом («Множество точек»); прямая по двум кликам, тренд (прямая в осях, линейный, степенной, лог., эксп., полином), информация о прямой (уравнение, наклон, угол, R²), правка прямой (Ctrl — только по горизонтали, Shift — только по вертикали, Alt + узел — удлинить/укоротить). Отрезок по двум точкам (с Ctrl — прямая на весь график), кривая через узлы (сплайн, как в чертёжных программах). «Вид точек»: размер, прозрачность, прореживание, скрытие и цвет серий.
- **Построитель графиков** — отдельный вид для работы только с графиками: данные графика загружаются как есть, без пересчёта (например, выгрузки log-log или √t из Saphir), шаблоны шкал, «+ Серия» к графику, наложение нескольких графиков, таблица данных активного графика; прямые, кривые и инварианта для калькулятора работают так же.
- **Калькулятор** — площадь поверхности трещин ГРП и полудлины по инварианте (наклон на графике √t); выбор единиц у каждой величины с автоматическим пересчётом; все исследования, выбранные или группы.
- Проект автоматически сохраняется в браузере; «Проект → Сохранить в файл» — перенос на другой компьютер.

## Разработка

```bash
npm ci
npm run dev        # локальный сервер
npm test           # тесты расчётного ядра
npm run build      # сборка в dist/
```

Стек: Vite, React, TypeScript (strict), zustand, zod. Графики — собственный движок на Canvas.

Структура: `src/core` — расчёты (формулы, таблица, ГДИС, регрессия, ГРП, единицы), `src/charts` — графики, `src/table` — таблица, `src/dialogs` — окна, `src/calc` — калькулятор, `src/ui` — панели.

## Публикация

GitHub Actions (`.github/workflows/pages.yml`) собирает сайт и публикует его на GitHub Pages при каждом push в `main`. В настройках репозитория: Settings → Pages → Source: **GitHub Actions**.
